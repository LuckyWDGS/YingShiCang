# 发现、搜索、详情页改版验收

交付版本：0.1.5-alpha / versionCode6，ARM64 debug。运行环境：雷电Android14，1920×1080；未操作物理手机。

## 已实现

- **首页导航**：主页位于栏目首位，增加热播电影、热播剧集、热播综艺、电影/电视筛选、电影/剧集榜单；历史独立入口，保留观看记录。常用功能改为紧凑横排。
- **栏目二次点击**：当前栏目再次点击展开/收起筛选，有选中状态与下拉标识。排序支持热度、最新、评分；地区支持全部、华语、欧美、韩国、日本。真实Douban接口按类型/tag/sort请求，不在本地假装筛选。
- **发现片单**：主页交错展示电影和剧集，首批40部，加载更多至80部已验证；分类20部/页。取消旧请求避免快速切栏目串页；失败可重试。没有恢复之前要求移除的更新推荐。
- **卡片**：继续四列，统一圆角、海报内渐变片名、评分/来源角标，去掉大块卡片底座。结果页按自身实际列宽排版，修复旧页面卡片按整屏宽度计算导致右侧裁切的问题。
- **真实关键词**：使用爱奇艺关键词服务，加上其相关词数量参数`rltnum=50`；XF实测返回24项（默认接口10项），包括小芳、校服的裙摆等。接口返回多少显示多少，不编造词、不把参数50当成保证返回量。
- **结果布局**：左上单独显示搜索进度和源总数，窄站源栏，左下排序（到达顺序/片名/来源），右侧清晰标题、数量和四列卡片；有源筛选与单源继续加载。
- **异步全源**：原逻辑没有30站上限；实际分母取已启用、支持搜索的站源数量。四个并发工作任务持续消费全部队列。修复异步批次错误加入当前选中站源页面的旧问题，以及旧查询主线程回调污染新查询的问题。跨源相同影片ID使用来源+ID区分。
- **详情页**：左侧16:9圆角播放预览，右侧标题、精简资料和三行简介；快速搜索、倒序、简介、收藏集中；下方播放线路和六列等宽选集。长列表可滚动，保留分页跳集；短剧集不重复显示旧倒序栏。

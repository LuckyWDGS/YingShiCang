# 自动天气、导航层级与卡片提案（2026-09-27）

已交付代码：TV / Mobile 0.1.13-alpha（14）。TV改动安装到LDPlayer127.0.0.1:5555。

- 自动网络定位城市，移除手动输入与选择弹窗。迁移时清除旧手动地点及其缓存，避免把手动地点天气继续当作自动定位；保留30分钟真实天气缓存、过期提示和生命周期取消。IP定位对应网络出口城市，代理网络会影响地点。
- 天气画布从56×42dp缩为36×28dp，容器36dp，动画按比例缩放。天气为被动显示，不再占遥控焦点。
- 内容导航：8个等宽文本标签，细下划线表示选中。功能导航：6个等宽图标胶囊，历史、直播、搜索、收藏、推送、设置；无直播配置时按5格平分。移除点播入口。保留清晰遥控焦点描边、单击行为和分类重复点击展开筛选。

## 数据和状态约定

- 历史Episode来自History.vodRemarks，当前仅保存集名，无总集数字段。落地需给历史增加当前集/集数元数据并完整处理数据库迁移、copy/merge、播放换集、倒序列表、来源切换。
- VodHistoryPolicy.updateEpisode拥有当前Flag/Episode，可获取该线路可播集合；集合长度是当前可播集数，不一定是作品完结总集数。明确完整总集数才写“共N集”，连载仅已上架时使用“已更新N集”或其他明确标签。
- 旧历史总数未知只显示“看到第3集”，不凭标题推断总数。裸数字1只在明确剧集语境归一为第1集，电影的正片/清晰度标签不能误转为集数。
- 普通卡片显示共N集/更新至N集/评分8.6等实际数据；无评分不伪造。
- 用户先看方案，卡片重构和旧历史迁移在选定方案后实施；既有默认缩略图A/B/C也仍未选择。

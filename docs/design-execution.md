# Alpha 设计与行为合同

本轮维护页采用已有原生控件体系，不需要图片素材。大规模首页／播放器视觉重设计尚未落地；不能把当前上游界面作为已定稿设计。

| 范围 | 实现目标 | 数据／动作 | 状态与验收 |
| --- | --- | --- | --- |
| 设置中诊断与维护 | TV SettingActivity / mobile SettingFragment | 打开共享 MaintenanceActivity | 遥控器与触控入口；返回恢复原设置页 |
| 播放摘要 | PlaybackHealth | 最近一次真实会话的就绪时间、播放／缓冲时间 | 无样本明确为空；就绪不是首帧；未完成／错误必须可见 |
| 媒体测速 | MediaProbe | 上次媒体地址及原请求头，或用户输入直链 | 正在测试／取消／失败／完成；在播放时拒绝争抢带宽；HTTP、HLS 支持，DASH 未实现明确失败 |
| 日志占用 | RingLog | 设备真实文件字节数 | 最大总量 10MB；出现异常不阻断播放器 |
| 服务地址 | ServiceSettings | 本地保存更新和日志接口 | 空地址表示未配置；HTTPS 校验；仅调试版本允许模拟器宿主地址 |
| 检查升级 | Updater | 读取自有发布清单 | 未配置／检查中／无更新／新版本／失败分开显示；普通安装走系统确认 |
| 上传日志 | LogUploader | 冻结批次、流式发送、核对落盘回执 | 只清理确认批次；新日志保留；取消／失败可重试 |
| 维护结果 | 页面状态文本 | 展示实际结果 | 后台任务结束后切回主线程；销毁页面取消任务；旧任务不能覆盖新任务 |

维护页风险中等：网络和清理语义以单元／服务／模拟器验证为准。使用深石墨背景、白色文字和原生按钮焦点；TV 横屏与手机竖屏均可滚动。正式视觉稿和更细的 UI 层级优化仍在计划范围内。

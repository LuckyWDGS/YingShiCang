# 玩偶哥哥地址保护与站源复核

本轮修复了玩偶哥哥插件在刷新入口失败后清空内存地址的问题。真实设备验证确认：同一插件实例的有效地址在首页和三次搜索后保持不变。但三次搜索仍无内容，**尚不能把玩偶哥哥标为恢复可用**。光影、立播、文采的搜索也未恢复。

交付版本：`0.1.38-alpha / versionCode 39`。TV 版已安装到经过验证的雷电模拟器；手机版完成构建，未做手机交互验证。

## 根因与修改

对当前实际 `com.github.catvod.spider.WoGG` 的审查发现，`getKey()` 会先把刷新结果写入实例地址字段 `O`，随后才检查结果。所有候选失败时，原有效地址可能被空字符串覆盖。首页、分类或搜索可以触发刷新，详情和播放也读取该地址。

修复前 code38 的真实基线证明：同一实例初始化后地址长度为 21、是完整 HTTP 地址；首页调用后长度变为 0，插件重试标志 `n` 变为 true；随后三次真实 `SiteApi.searchContent` 都从空地址开始并失败。该观察不含完整地址，也没有注入测试地址。

新增 `WoggAddressCompatibility`，只匹配经过核对的 WoGG 类、地址字段和方法签名，以及直接转发相关回调的 `BaseSpiderGuard`。它按实际委托实例保存最后一个语法有效的 HTTP(S) 地址；一次回调返回或抛错后，只有地址变成空值或无效格式才恢复旧值，正常的新地址会保留。

`SiteApi` 的首页、分类元数据、分类列表、搜索、详情、播放和动作调用都参加同一实例的锁。等待锁有期限并可取消；不同实例可以继续并行。搜索使用已有 `SearchRequestScope` 的剩余时间，普通播放保留已有 30 秒调用预算。弱引用状态不持有插件或类加载器。

这一修改不增加网络请求、不更换站源、不改配置或偏好、不修改插件静态重试标志，也不替换原始响应与错误。它无法修复当前回调内部已经失败的重试，也不能强制取消插件自己的私有网络客户端。

## 公开入口调查

重新核对了公开配置列出的 WoGG 候选入口，以及历史原站的分类、搜索和详情路径。当前观察为验证页、TLS/网络超时、错误响应或域名停放，没有建立可用的同源首页→搜索→详情链。公开配置只提供候选出处，不能作为官方迁移证明。出处：[qist/tvbox jsm.json](https://github.com/qist/tvbox/blob/master/jsm.json)、[0825.json](https://github.com/qist/tvbox/blob/master/0825.json)、[公开 Wogg 源码](https://raw.githubusercontent.com/mymine/CatVodSpider/main/app/src/main/java/com/github/catvod/spider/Wogg.java)。该公开 `Wogg` 类与实际大小写不同的 `WoGG` 委托不是同一个已证明实现。

立播的可信发布链指向 [LIBVIO 发布页](https://libviogroup.github.io/)。其公开列出的 16 个主入口和备用入口没有提供正常目录。另有同品牌候选可以搜索并打开详情，但当前官方发布链没有把它们关联为原站迁移，因此保留原站源身份。

光影普通搜索表单的三词结果均为验证码页，原 API 三词搜索返回相同的非 JSON 拒绝内容。文采按原插件协议补充核查也收到 403；主机 UA 等价性未证明，这条补证不能代替上述实际产品请求。

所有网络观察均来自当前环境；系统代理、TUN、DNS和证书校验设置保持不变。没有把主机请求称为已证明的公网直连，也没有尝试绕过验证码或访问验证。

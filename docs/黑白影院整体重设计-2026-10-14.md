# 黑白影院整体重设计

版本：0.1.41-alpha / versionCode 42；2026-10-14。

用户在“全面改进整体主题”聊天中确认了黑白影院、柔和灰阶和简洁留白。本次覆盖首页、导航、快捷入口、筛选、海报卡片、搜索、详情、设置、线路弹窗及局域网配置与遥控网页；取代 v41 仅换色且冻结布局的方案。

## 完成的界面

- 黑色背景 #080808，面板 #141414，控件 #1E1E1E，选中态 #303030，文字 #F2F2F2 / #AAAAAA。白色边框表示遥控焦点，灰底和下划线/侧边标记表示当前选择；错误仍用语义红色。
- 首页使用 32dp 外边距、较轻的身份与状态栏、36dp 快捷按钮、18dp 图标和更明确的分类层级。九个分类和八个条件显示的快捷入口顺序保持。
- 筛选面板提高不透明度和内边距，亮海报不再干扰文字。首次点击分类、重复点击展开以及返回关闭的行为保持。
- 搜索保留三栏结构，结果保留五列海报、来源、评分和集数。详情、设置、公共按钮与线路弹窗统一圆角、灰阶和焦点；白底主按钮保留深色内描边。
- 详情简介解码 HTML 实体，缩略简介折叠空白，完整简介保留文本段落；不改变来源数据对象。
- 配置与遥控网页统一灰阶和焦点，沿用真实连接状态、URL 保存、当前线路及现有工具入口。

## 实现范围与约束

52 个文件的本轮差异保存在本地 `theme-only.diff`，主要是 leanback 资源、展示层 Java、网页 CSS 和版本号。更早版本的搜索、站源、直接局域网配置等未提交改动仍保留，不能把整个工作区 diff 视作本次主题改动。

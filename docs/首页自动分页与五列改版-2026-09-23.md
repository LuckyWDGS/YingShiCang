# 首页自动分页与五列改版

版本0.1.6-alpha / versionCode7，ARM64 debug，已安装雷电127.0.0.1:5555。

- 删除“主页·数量”行和底部手动“加载更多”。
- 首页及发现分类改为每行5张卡片；搜索结果保持原有4列。
- 接近末尾两行时自动加载下一页；正在加载时阻止重复请求，切换栏目取消旧请求，结束页停止。失败通过临时提示提供重试。
- 新数据只追加到已有卡片后，不重建之前的卡片和滚动位置。
- 右下悬浮“回到顶部”，顶部自动隐藏；保留当前栏目和已加载片单，不重新请求。
- 无星星数字评分角标，暖金底色、深色数字；无评分使用低对比标签。卡片调整圆角、细边框、间距与标题渐变。

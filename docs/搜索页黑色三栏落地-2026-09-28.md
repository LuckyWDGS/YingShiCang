# 搜索页黑色三栏落地 — 2026-09-28

版本：TV/手机 0.1.20-alpha（versionCode 21）。只改电视端（leanback）搜索输入页；结果页、卡片、线路、数据均未改。

## 改动

- `activity_search.xml` 重写为参考图结构：左栏历史胶囊、中栏源/输入/按钮/6×6 键盘、右栏热门三榜。去掉顶部「影视仓+｜搜索」和「返回首页」，去掉三块嵌套面板。
- 纯黑配色：底 #050505，控件炭灰 #1C1C1C，文字 #EDEDED，焦点白色 2dp 描边；「搜索」为白底主按钮，获焦时内圈黑环。尺寸按 960×540dp 设计稿（1080p 下 2px/dp）对齐参考截图：按钮/键 37dp、胶囊 36dp、榜单标题 22sp 粗体。
- 新样式 `SearchBlackKey/Primary/Chip/Heading` 与 `search_black_*` drawable、`color/search_black_text.xml`；旧 `SearchControl` 保留（播放页「倒序」按钮仍在用）。
- 历史：竖排整行 → Flexbox 胶囊；底部小字「长按记录可单独删除」；删除后焦点留在相邻记录，清空后回到键盘。
- 焦点：遥控进入默认落在「A」；新增 `SpatialFocus`，修复换行胶囊在行首/行尾按左右会跳到上一行/下一行的问题；输入框按右键不再跳到键盘。
- 状态文案：正常时隐藏；仅在「榜单加载中…」「部分榜单暂不可用」「暂无相关关键词」等需要提示时显示。
- 空搜索提示「请输入要搜索的内容」；长按「删除」清空输入。

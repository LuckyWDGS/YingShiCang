# 筛选透明度与分类页顶部栏 · 1.0.3

版本：1.0.3 / versionCode 59。沿用已有正式签名，可直接覆盖升级。

## 本次修改

- 根据用户图二调整筛选透明度：底板使用约 35% 不透明度，普通选项使用半透明深灰；选中、按下和遥控器焦点保留较强填充。文字和白色焦点描边独立保持清晰，筛选行标题提亮。
- 根据用户图三、图四调整分类切换：非首页分类及历史页收起顶部站源、天气、时间和历史/设置快捷栏，分类与列表上移；返回首页恢复。
- 隐藏顶部控件前检查焦点，必要时将焦点移回可见分类，避免遥控器停留在隐藏区域。保留首次点击切换内容、重复点击展开筛选、返回键优先收起筛选的交互。
- 参考图仅覆盖透明度与两栏显示行为；现有九个入口、卡片、主题和实际来源数据继续沿用。本次没有新增图片、模糊效果或逐帧动画计算。

## 验证

- TV ARM64、ARMv7 最终签名正式包构建成功，mobile ARM64 编译成功。两个正式包的应用 ID、版本、非调试属性、v2 签名、原发布证书及 16KB 对齐检查通过。
- 最终签名 ARM64 包在雷电模拟器完成 31 项检查：稀疏与多行实际筛选、遥控器左右移动、首行向上回分类、分类向下进入筛选、返回键关闭并恢复焦点、隐藏顶部控件不可获取焦点、跨分类关闭旧面板以及返回首页恢复布局。
- 真实海报上的底板测量为 34.82% 不透明度，目标为 34.90%。已目视检查亮色海报上的行标题与选项、稀疏筛选、多行筛选及首页恢复画面。
- 前一轮已完成全部八个非首页分类与历史/返回路径检查。该轮随后因测试脚本误用筛选行名称而停止；更早一轮在初始配置加载完成前导航，不属于完整通过记录。最终轮修正了等待条件和真实标签选择器后通过。
- 最终轮完整备份并按 SHA256 和文件清单恢复全部 1223 个原有内部文件及外部目录；保留原 ADB 映射、移除临时测试工具并回到首页。已安装 APK 与分发包 SHA256 一致，前两轮也已恢复数据。
- 本次为 TV 显示与布局调整，未重复历史 JVM 全量测试；mobile 仅编译，未在实体设备验证，也未测试全部来源播放或长时间帧性能。

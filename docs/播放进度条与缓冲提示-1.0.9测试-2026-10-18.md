# 播放进度条与缓冲提示：1.0.9 测试包

本轮完成连续时间条、章节指针、缓冲建议静默，并修正真实鼠标和遥控混用时的焦点问题。重复扫码与偶发低帧率仍待具体网盘、原片源复现，不能列为已解决。未发布远端 Release。

## 已修改

- TV 点播时间条不再按章节断开；已播、缓冲和未播轨道保持连续。真实章节起点以轨道上方的小三角显示，重叠标记仅在绘制时合并，原始章节位置、名称及拖动气泡保留。
- 删除持续缓冲时建议切换清晰度的弹窗及其定时调度，保留手动清晰度入口和既有最高画质选择行为。
- 鼠标操作有效时间条时保留原生进度条焦点；只记忆控制区内合法焦点，避免视频区域成为遥控恢复目标。控制区显示且焦点在区外时，方向键可恢复控制焦点。
- 新增被动视频诊断：解码器、视频格式、状态、缓冲、渲染与丢帧计数；帧统计按事件触发并节流，写入既有异步有界日志。不记录播放地址、标题或认证信息，不改变解码或播放参数。
- 续修补充首帧与 codec 观测：`playback_video_first_frame` 记录首帧渲染时刻，`playback_video_codec_error` 只记录异常类型；帧窗口增加解码器计数推导的 `renderedPerSec`。这些字段只用于区分供给、解码和呈现阶段，仍不代表 Surface 实际呈现帧率，也没有改变播放器策略。

## 雷电实测

设备为允许的雷电 Android 14 目标，使用正式证书签名的 TV ARM64 包。操作使用真实鼠标事件与 DPAD 遥控事件。测试视频来自本地受控 HTTP 服务，720p H264/AAC，具有真实 MKV 章节；不能视为线上网盘认证或所有片源验证。

- 鼠标前拖、后拖，拖动后直接接续遥控，左右快进快退通过。
- 鼠标和遥控上下集、进度条上键返回控制栏、普通控制顶边、更多菜单两列导航、返回与再次显示控制栏通过。
- 鼠标/遥控拖动截图确认连续轨道、章节三角与真实章节气泡；气泡为画布绘制，UI 文本树不包含其文字。
- 片头/片尾保存实际时间、遥控上下按一秒调整、长按清零、重播应用片头、越过片尾自动换集通过。
- 人为暂停服务传输，缓冲耗尽超过十秒未出现清晰度建议；恢复传输后继续渲染。

初包三段各约十二秒观测结果：

| 源帧率 | 渲染计数估算帧率 | 新增输入/输出丢帧 |
| --- | --- | --- |
| 25fps | 24.27fps | 0 / 0 |
| 30fps | 29.97fps | 0 / 0 |
| 60fps | 59.44fps | 0 / 0 |

这些是解码器渲染计数的短窗口采样，不是 Surface 实际呈现帧时间，也不能覆盖线上 4K/HEVC/HDR 或长时间播放。尚未复现用户描述的 PPT 式低帧率，不能声称卡顿已修复。

测试历史保留了中间包的真实混合输入焦点失败，以及最终包早期两条脚本误判：把画布章节气泡当成可访问文本、设置片尾立即换集后仍使用旧集数预期。后者已修正并重新验证，不能把整个历史记录称为全部通过。

## 重复扫码的调查范围

已确认插件使用应用内部偏好和文件保存凭据，未发现宿主正常清缓存删除登录数据的证据。已审计的一条 UC 校验路径会把网络异常和非成功 HTTP 响应也转成认证失败，触发重新登录；其它网盘路径条件不同，不能一概归因。

当前没有经验证、同时覆盖插件同步与异步认证的安全宿主接口。未采用伪造登录成功、自动恢复主动退出凭据或跨插件异常逃逸补丁。需要具体网盘名称，以及扫码成功后再次要求扫码的最短操作步骤，才能区分未落盘、未复用、会话失效和暂时网络失败。

卡顿复现时还需异常时间、当时声音是否连续、原片清晰度，以及对应解码器/缓冲/渲染计数，继续定位网络供给、解码和呈现阶段。

## 构建与交付边界

TV ARM64/ARMv7 release 构建和共享 mobile release Java 编译通过；正式证书、包名、1.0.9/code65、minSdk24、单 ABI、非 debug、v2 签名和 16KB ZIP 对齐检查通过。没有进行手机交互验收。

本地包为测试交付。此前三网盘二维码界面尚未接入生产插件认证桥接，本轮也未解决重复扫码，因此不作为正式远端 v65 Release 发布。

私有测试证据、日志和完整数据备份位于 Git 忽略目录；不随代码提交。每轮测试均恢复原始内部/外部数据并核对 SHA 和完整清单，保留原 ADB 映射，移除测试 probe，返回首页。

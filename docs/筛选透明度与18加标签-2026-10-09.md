# 筛选透明度与 18+ 成人向标签（2026-10-09）

本轮针对用户提供的电影 / 电视筛选截图修改现有界面。版本 **0.1.22-alpha / versionCode 23**。用户确认“18+”指成人向 / 限制级影视标签。沿用现有主页和筛选控件，未生成新的设计图。

## 修改

- 面板背景从约 **98% 不透明**降至约 **32% 不透明**，即约 68% 透明；海报和片名能够透过面板显示。只调整筛选背景与专用按钮背景，文字保持完整不透明，并加轻微暗色阴影。选中状态与遥控焦点保留较实的背景和边框。
- 电影筛选、电视筛选顶部新增独立的 **内容：全部 / 18+（成人向）** 行。不会替换原类型，仍可与喜剧、地区、年代、平台及排序组合使用。
- 选择独立保存；旧配置缺少此项时默认“全部”。“重置”清除成人向条件。选择改变实际请求，分页继续使用当前条件。没有添加虚构结果或新的数据源。
- 长按 / 悬停提示说明数据源标签。兼容 API 24 的提示实现使用 TooltipCompat；新标签沿用当前水平滚动及垂直面板、点击 / 遥控焦点流程。
- 电视筛选新增行后仍限制面板高度，底部平台可滚动到达。修正高筛选面板内第一行向上被 ScrollView 截到“重置”的行为，明确返回当前栏目。

代码：DiscoveryCatalog.java、HomeDiscovery.java、discovery_filter_panel.xml、新增 discovery_filter_control.xml、版本配置及相应模型测试。通用 browse_control 未修改，搜索、卡片 / 集数 / 评分、天气、配置与线路设计保留。

## 实际标签含义

“18+（成人向）”映射到豆瓣的 **情色题材标签**。该来源有真实的[题材分类入口](https://movie.douban.com/chart)，本轮直接核对推荐接口：追加 `tags=情色` 会收窄片单，并与类型、地区、年代组合生效。接口的字面 `18+` 结果混杂，`限制级`没有可显示结果，因此未使用它们。当前响应没有可靠的正式年龄评级字段。

这项筛选覆盖情色题材，不能代表全部因暴力、恐怖等被划为限制级的作品；页面未把影片评分或题材标签标为官方年龄认证。详细参数、计数与返回元数据核对：`.codex/session/research/discovery-adult-tag-probe-2026-10-09.md`。

同入口刷新失败时保留前一次片单，同时显示“刷新失败，仍显示上次片单”及重试按钮；窄组合的真实空结果继续显示空片单，不放宽条件。请求超时、取消旧请求和分页去重沿用原实现，不增加逐片网络请求。

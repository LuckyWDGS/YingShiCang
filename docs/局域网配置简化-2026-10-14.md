# 局域网配置简化

版本：0.1.39-alpha / versionCode 40。

同一局域网内，浏览器输入电视「配置」显示的 `http://IP:端口`，即可打开配置中心。配对码、登录步骤、临时访问 token 与有效期已移除，二维码直接编码相同的根地址。端口仍使用服务实际选中的 9978–9998，不写死。

配置网页沿用现有深色风格，电脑为双栏、手机为上下排列，主要内容为「添加配置」和「已保存线路」。只需粘贴 TVBox 配置链接，名称自动识别；相同链接不会重复添加。保存后由用户在电视「线路」中选择启用，添加不会切换当前配置。列表保留当前线路标记、刷新与重试；保存失败保留输入，刷新失败保留已有列表，空列表与读取失败分别提示。

## 相连入口

- 默认 `/` 与原 `/sources.html` 均进入配置中心；`/api/sources` GET、POST 直接可用，旧登录接口返回 404。
- 遥控、推送和其他工具继续使用 `/index.html?tab=N`。旧 `/?tab=N` 书签仍可打开对应工具。
- 旧设置页突出配置中心入口，将给电视当前直播、壁纸、UA、弹幕、Mpv 等设置发送输入的表单放入「其他设置输入」，保留其原事件处理。字幕 API 的独立 token 保持原有行为。
- URL 校验、自动名称、原数据库及重复链接处理不变；网页不新增切换、删除或云端配置功能。

- 在经守卫验证的雷电模拟器上安装 TV 版。实际接口验证根页面、配置页、显式与旧书签工具路由、无需凭据读取、非法 URL 的 400、登录接口 404、不支持的方法 405 与 no-store。
- 浏览器通过真实接口添加测试配置、重复同一链接、添加长名称配置：自动名称正确、重复不增加条目、当前线路不变且新增条目未启用。测试配置仅存在于隔离验收期间，结束时删除并恢复原数据库。
- 浏览器 1280px 双栏、390px 和 320px 单栏布局均通过；长名称换行、无横向溢出、当前标记可读。隔离的空响应及断网响应覆盖空状态、首次读取失败、重试、保存失败输入保留、刷新失败列表保留与 Ctrl+Enter 提交。恢复真实接口后正常读取，控制台无警告或错误。

验收使用模拟器 NAT 下的 ADB 转发与 Chromium 手机视口，未测试实体电视/手机的实际 Wi-Fi 网络。Mobile 版完成构建，未覆盖设备交互；本次不涉及播放或上游站源恢复。

# 播放常用入口补充 · 1.0.5

用户指出播放条中“片尾”与“更多”之间仍有空白。本次从“更多”提升字幕、弹幕、音轨、画面比例四项，按日常观看的使用频率排列，并共享剩余宽度。比例按钮直接显示当前值，如“原始”“16:9”。

主条顺序为：下集、上集、刷新、重播、选集、倍速、片头、片尾、字幕、弹幕、音轨、当前比例、更多。解码、渲染、循环、屏显和来源扩展操作继续放在“更多”。四项复用原按钮、处理器和能力判断，未新增设置副本。

## 实际验证

在雷电 `127.0.0.2:5555` 安装最终正式签名 ARM64 包，用真实 DPAD 按键和 mouse 点击操作。只读 UI 探针用于取证，未调用焦点或播放器方法代替输入。实际播放《我的三体之章北海传》第03集，并切到04集后返回03集。

本轮30项检查全部通过：

| 范围 | 结果 |
| --- | --- |
| 主条布局 | 1920×1080 下全部按钮可见，原空白填满，无重叠；字幕遥控焦点清晰 |
| 字幕、弹幕、音轨 | 遥控和鼠标均打开原选择弹窗；字幕空轨提示、搜索和导入入口保留；音轨显示真实 AAC 轨道 |
| 设置子页 | 遥控打开字幕样式设置；鼠标打开弹幕设置，原分页和返回正常 |
| 比例 | 遥控切换原始→16:9，鼠标切换到4:3；遥控继续循环并回到原始，标签同步更新 |
| 焦点与返回 | 四项和更多可逐项遥控到达；更多向左回比例；比例向下到进度条；更多超时仍保持，返回键关闭后回到触发按钮 |
| 更多及来源扩展 | 无迁移项重复，两列排列正常；来源追加“弹幕云搜”可遥控进入，并打开原搜索界面 |
| 上下集刷新 | 鼠标下集03→04、遥控上集04→03后，四个入口仍存在 |
| 崩溃 | 测试前、动作完成后、恢复后 crash buffer 均为空 |

一次辅助导航脚本在来源弹窗返回“更多”后，误按已经回主条的前提导航而中断；补一次真实返回关闭“更多”后继续通过。该中断未计为产品缺陷，也未把中断批次称作完整通过。

本片源没有内嵌字幕、仅一个音轨。弹幕选择器存在来源候选。本轮只确认入口、设置和导航可用，未据此宣称字幕渲染、滚动弹幕或多音轨切换通过。未覆盖无音轨时的运行时隐藏、大字体、小分辨率和全部片源。

## 修正旧审计的两处判断

- 2026-09-29 的审计和 `hot-filter-verification.md` 写“热播综艺未发现筛选”，这是较早检查的不完整结论。后续 `live-hot-variety-filter.xml` 已明确包含“综合 / 国内 / 国外”。
- 旧审计建议“电影 / 电视筛选按 TVBox 站源动态 filters 生成”。本轮应承接上述豆瓣发现标签与榜单模型：现有 `HomeDiscovery.java` 本身从 `movie.douban.com` 请求发现片单；这些固定发现条件不能被当前 TVBox 播放站源的分类替代。TVBox 内容分类与豆瓣发现属于不同数据入口。

## 本轮应完成的行为

- 七个入口分别使用自己的筛选模型；真实选项改变请求参数并刷新片单，不能只改标签高亮。
- 入口切换单次点击立即生效；再次点击已选入口可以展开或收起筛选。鼠标和遥控器均可操作。
- 电影、剧集、综艺和榜单状态独立；离开再返回保留各自选择。返回键先关闭打开的筛选面板。
- 四行 / 七行筛选可完整到达，长行能够横向浏览，焦点不会因更新标签而丢失。
- 刷新提供加载与失败重试反馈；取消过期请求，分页沿用当前条件，失败时尽量保留原片单。
- “电视剧榜单”的文案与旧版统一。现有五列卡片、详情搜索链路、自动分页和回到顶部继续沿用。

## 已完成、冻结与延期范围

- **已有完成记录**：首页按钮单击、鼠标滚动回顶修复、首页入口、动态天气 / 年份日期、两层导航、五列卡片 / 自动分页、搜索速度与返回路径、黑色三栏搜索页、配置扫码 / 局域网推送 / 自动命名、线路切换删除和垃圾桶样式。完成状态来自此前交付记录；本轮仅对受影响行为回归，不把历史记录冒充本轮验证。
- **冻结**：用户明确“搜索页搞定了，你不需要管了”；另明确“卡片样式的剧集评分等样式暂时不动”。保留现有搜索、卡片 / 评分 / 集数、天气、配置和线路设计。
- **被否定**：`generated-images/hot-filter-options-v1/` 的 A / B / C 三版热播设计被用户评价“都不好”。本轮以真实旧版分类行为与现有主题为依据，不采用这些设计，也不继续等待选择它们。
- **延期 / 未选择**：历史“第几集 / 共几集”新设计、三款默认海报、远程搜索二维码 / 搜索源选择器、网盘模块，仅有提案或参考图，没有新的选型指令。
- **较大计划中的未验证事项**：夸克完整授权播放、生产云服务、质量自动优选、长时间 / 低性能测试。它们不是本聊天最新七入口分类要求的附带修复；不得宣称本轮已完成。

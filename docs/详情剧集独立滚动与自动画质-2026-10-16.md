# 详情剧集独立滚动与自动画质

版本：0.1.53-alpha / 54。

按用户提供的影视仓详情参考调整电视版：剧集使用六列网格，独占纵向滚动；播放器、站源信息、播放线路和右侧四个操作固定。移除分词搜索、底部倒序/箭头/集数分段行，右侧保留倒序。快速搜索和收藏使用蓝色胶囊按钮，倒序和内容简介使用绿色，遥控器焦点仍有白色边框。

最新追加要求同时移除清晰度整行。电视版针对每次播放及下一集预加载，根据站源实际返回的画质名称选择最高已识别选项，支持常见分辨率、4K/8K和高清/标清等标签，不依赖返回顺序。同等画质或无法识别的标签保留站源默认选项；不会从地址猜测画质、编造选项或修改站源地址。手机版仍使用原有手动画质行为。

剧集名称及播放身份沿用站源数据，特殊篇、花絮不改成列表序号。其他来源的自动回退及手动选择优先规则保留。真实备用来源列表固定在剧集下方，仅有内容时显示。

实现：移除外层 NestedScrollView，由占剩余高度的 EpisodeGridView 负责滚动并裁剪越界项；删除电视版不再使用的 Array/Part/Quality adapter 和布局。详情页使用独立按钮及剧集背景资源，不修改全局控件。VodPlaybackHost 的默认画质选择保持原行为，电视版单独覆盖；控制器和预加载统一调用该策略。

验证完成：两种 ARM64 debug 构建成功，8 项相关 JVM 测试通过（6 项画质排序边界、2 项已有回退状态）。最终雷电安装包通过 31 项真实配置检查和 29 项受控边界检查：真实历史详情、滚动前后固定区域坐标、控件移除、按钮配色和方向键焦点、收藏及恢复、简介/搜索返回、全屏返回、49 项剧集末尾特殊篇、三线路切换、短列表、倒序、乱序画质选中第三项4K地址、延迟备用来源不抢手动选集及来源切换。真实及受控截图已人工检查。

两轮最终验证各恢复16个原始数据库/伴随文件/偏好，逐文件 SHA 与清单校验通过；ADB 映射保留，最终返回首页；安装包 SHA 与归档一致。前期两个旧脚本分别因清晰度显示假设、点击已选集进入全屏而停止，已修正脚本后完成最终检查，不计为完整通过。

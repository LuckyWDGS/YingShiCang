# 1.0.3 雷电日常使用测试

测试日期：2026-10-17～18。结论：本次顶部收起、筛选展开与返回首页的主要改动路径正常；普通使用测试复现了历史返回跳焦点，以及两项分类加载恢复/资源使用风险。另有返回行为一致性和内存增长需要优化或继续确认。没有据此修改产品代码或再次发布版本。

## 已复现问题与建议

以下均无崩溃或数据损坏证据；P2 表示值得修复的使用问题或资源风险，未发现阻断本次视觉改动使用的 P0/P1 问题。既有行为不能直接归为 v59 新回归。

| 优先级 | 现象与复现证据 | 使用影响及建议 |
|---|---|---|
| P2 | **从详情返回历史，焦点跳到顶部“主页”按钮。** 两次均通过遥控确认键进入详情，再按 Back；历史列表仍显示，唯一焦点变为 `id/home`。原第三项被移到首位本身正常。 | 用户要额外找回历史卡。重建历史列表时按影片身份恢复焦点；刚观看项目移位后跟随其身份，不固守旧索引。关联 `HomeActivity.java:342–349,412–413`。 |
| P2 | **普通筛选连续空匹配时自动扫描过多页。** 临时源声明 500 页，每页唯一影片均为 1999 年；已选择 2026。无后续输入，连续成功请求第 1～20 页，观察窗口 2.91 秒。第 21 页由测试服务主动返回 503 截停。 | 可能消耗网络、解析与电量，让用户长时间等待。建议增加连续无新增结果页数/总时间预算，达到后提供可聚焦的“继续查找”，保留各源原始游标。关联 `HomeDiscovery.java:530–545`；`SourcePageCursor.java:18` 有 500 页硬上限。**没有实际测试 500 页，测试截流不是产品故障。** |
| P2 | **自动重试耗尽后缺少直接重试入口。** 独立失败阶段请求第一页共 3 次（首次加两次自动重试）后停止。服务恢复后，点失败提示无新请求；再点当前分类仅展开筛选，也无新请求；切首页再进入产生 1 次请求并显示恢复卡片。错误行及父行均不可聚焦、不可点击。 | 恢复方式不明显。建议错误行提供遥控可达的“重试”，仅重试失败源并保留已有片单。重试预算本身有必要保留。关联 `HomeDiscovery.java:397–400,617–631`、`activity_home.xml:17–18`。 |
| P3 | **普通分类的 Back 去向随滚动位置变化。** 顶部且筛选关闭时离开应用；向下浏览后按 Back 回首页。历史则固定回首页。 | 同一个动作容易让人误退。建议普通非首页分类统一先回首页，由首页承担退出动作。关联 `HomeActivity.java:556–569`。属于现有交互一致性问题。 |

空扫描、失败重试和 Back 对应逻辑并非 `c94e24a` 本次头栏/透明度修改新增。历史跳焦点与列表刷新路径吻合，但本轮没有旧版对照，不声称它是 v59 引入。

## 性能观察与待确认风险

使用独立的 `gfxinfo framestats` 短采样，采用现代帧 deadline 口径。雷电 legacy jank 和 input latency 计数出现不一致，不混用这些口径。

| 流程 | 样本 | 现代 jank | P50 / P90 / P95 / P99 |
|---|---|---|---|
| 首页静置，第 1 次 | 约 5.06 秒，610 帧 | 0 | 8 / 9 / 9 / 12 ms |
| 首页静置，第 2 次 | 约 5.08 秒，612 帧 | 2，0.33% | 8 / 10 / 11 / 15 ms |
| 收起头栏的分类静置，两次 | 各约 5 秒，均 0 帧 | 无可统计样本 | N/A |
| 筛选展开、Down、Right、Back，10 轮 | 共 51 帧 | 2，3.92% | 5 / 8 / 19 / 32 ms |

分类静置零帧支持“隐藏天气后未持续触发绘制”，但不能证明没有定时器、定位或网络任务。零帧输出中的 4950ms 百分位是空样本占位，无性能意义。交互样本较小，不能从两帧超时推断根因或回归；模拟器的绝对表现不能代替真机。

**需继续确认：分类往返后进程内存上涨。** 三次回到首页后的 TOTAL PSS 分别约 278.7、302.7、333.6 MiB，较基线增加约 54.9 MiB。Activity 为 2→1→1，View 为 247→220→220；没有继续累积 Activity/View 的迹象，但 AppContexts 为 20→24→44。期间执行了筛选开关及 12 次分类/首页往返，来源和海报缓存仍在变化，基线 Activity 数也不同。建议下一轮固定片单和暖缓存后重复同一流程，再检查内存能否回落；需要时采堆转储确认保留链。**当前既不能认定泄漏，也不能宣称没有泄漏。**

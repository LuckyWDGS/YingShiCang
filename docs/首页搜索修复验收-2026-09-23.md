# 首页与搜索页中断任务修复验收

版本：0.1.4-alpha（versionCode 5），ARM64 debug。验证环境：雷电 14 / Android 14 / 1920×1080，ADB 127.0.0.1:5555。未操作物理手机。

## 需求与交付

| 用户要求 | 实现 | 验证结果 |
| --- | --- | --- |
| 按钮需要点两次 | 可操作控件保留遥控器焦点，关闭触摸先聚焦；移除手写抬手强制点击。输入框和播放器触摸面保留原生输入能力 | 鼠标单击点播、直播、搜索、收藏、推送、设置，均进入对应 Activity |
| 鼠标向下滚动总回顶 | 首页外层改为标准 RecyclerView/GridLayoutManager；固定顶部工具栏，取消焦点驱动的隐藏/对齐跳动 | 先留下 D-pad 焦点，再注入实际 ACTION_SCROLL 鼠标事件；连续下滚、等待、对比卡片坐标，无回弹 |
| 首页按钮 | 顶部“首页”返回列表顶部；搜索页“返回首页”清理子页面返回主界面 | 点击回顶、搜索页返回均通过 |
| 日期、时间、天气 | 日期星期秒钟实时更新；网络出口城市 + Open-Meteo 真实天气；点击可搜索/选城市；30分钟缓存和失败提示 | 显示真实天气，城市搜索返回真实候选项；测试取消选择以保留自动城市 |
| 豆瓣卡片改名与评分 | 栏目“豆瓣精选”，左上角暖金评分；缺评分显示“暂无评分”；不以“热播”伪装评分 | 样本7.5、9.5、6.3等真实值与缺评分状态可见 |
| 缺缩略图 | 豆瓣 CDN 请求补 Referer/UA，优先较高清尺寸、原地址回退；临时失败缓存不再永久阻止重试 | 万物生灵第七季、黑白清道夫原先缺图的封面已加载 |
| 移除更新推荐 | 删除该区块的渲染链，保留点播分类所需源数据 | 首页仅保留功能、历史、精选，无更新推荐 |
| 四列、美化卡片 | 固定四列、统一间距、圆角海报、深色卡面、两行片名、评分角标与焦点边框 | 运行图四列显示，片名和角标可读 |
| 搜索页按图先设计再执行 | 基于上传图生成设计稿，然后实现左历史 / 中键盘 / 右分类榜单 | 设计稿与原生运行图三栏结构一致；生成图实际1672×941，运行1920×1080 |
| 搜索操作完整 | 六列字母数字、搜索/清空/删除/远程、来源选择、历史清空确认；真实电视/电影/综艺榜，取消过时联想响应 | 鼠标依次ABC→删除AB→清空、来源弹窗、远程页、清空历史取消、返回首页通过 |

## 构建与运行验证

- TV 与 mobile ARM64 debug 构建成功；14项现有 JVM 回归测试全部通过。本轮没有把旧测试冒充为新 UI 自动测试。
- 所有 leanback 资源 XML 解析通过；审核输入控件没有被批量设成不可触摸聚焦。
- 实际搜索“三体”进入 CollectActivity；截图时22/30源已响应，96个有效结果、1源失败。仅证明真实搜索流程可用，不承诺外部源全部可用。
- 遥控器移动焦点、确认进入页面，海报拖动取消不误触；鼠标轮与触摸滑动均验证。
- 安装后实际包版本号为5/0.1.4-alpha，来源与原有搜索/观看历史保留。
- 崩溃缓冲内只有测试用 WheelInput shell 辅助程序初版的异常，没有发现本轮应用进程崩溃。辅助程序已修正为 InputManagerGlobal 并完成滚轮验证，不随 APK 发布。

## 验证边界

天气自动城市是网络出口城市，代理/VPN会影响它，可手动选择；外部天气、榜单、海报、播放源失效时仍可能展示降级状态。没有编造天气、评分或封面。

此前另有夸克登录播放、生产云端部署、长时间弱网/4K测试和自动来源质量排序待办，需要相应账号/服务或独立测试。本次交付完成本轮首页与搜索 UI 请求，不把这些旧事项标记为已解决。

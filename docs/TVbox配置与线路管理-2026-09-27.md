# TVbox 配置与线路管理 — 2026-09-27

版本：0.1.15-alpha /16。TV/mobile ARM64构建成功。最终TV安装至LDPlayer127.0.0.1:5555；未操作物理设备。

## 入口与使用

首页第二排：历史、配置、线路、直播、搜索、收藏、推送、设置，等宽8格；无直播配置时7格。原卡片、评分、集数、自动天气与带年份时间不变。

配置：名称+HTTP(S)链接；可直接保存，也可保存并启用。二维码打开本机 /sources.html 并自动配对；同一局域网输入显示地址后用6位配对码登录。会话15分钟，连续5次错误暂停1分钟。二维码采用可识别标准黑白码，链接跟随实际9978–9998可用端口。手机端为响应式页面，保存结果和失败原因可见；没有云端账号。

线路：展示已保存整合源而非内部站点，当前标记，点击加载与切换；无效配置恢复原VOD对象/选中线路和最近解析器；加入相同链接更新名称，保存不会更新时间或激活。当前线路删除禁用；其他删除需确认，会依既有规则连同该线路历史/收藏删除。饭太硬保持用户真实配置，未内置或猜测肥猫地址。

## 代码

- SourceInput / SourcePairing / SourceManager：校验、配对会话、保存和切换互斥。
- Sources + Nano：/api/sources/login 与认证GET/POST /api/sources；JSON状态、no-store，不开放跨域。
- sources.html、css/sources.css、js/sources.js：手机/电脑局域网配置页，原推送页配置栏增加入口。
- SourceConfigDialog / SourceLineDialog、dialog_source_config、Func/HomeActivity及两个图标：TV入口与弹窗。
- VodConfig.switchWithRollback：保留旧配置对象，成功更新新配置；拒绝无站点对象；尽可能后置直播/壁纸副作用。BaseConfig区分真正取消与网络超时，确保超时报错而不是永远忙。
- QRCode增加独立标准黑白方法，原其他页面二维码不变。无数据库迁移。

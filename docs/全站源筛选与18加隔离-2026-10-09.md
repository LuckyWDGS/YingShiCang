# 全站源电影／电视筛选与 18+ 隔离

版本 0.1.24-alpha / versionCode 25。用户指定：首页不展示 18+，仅在电影筛选、电视筛选里主动选择后展示；这两个入口使用当前配置全部站源。

电影／电视筛选已接入当前 VodConfig 的全部有效站源，包含 searchable=0 的站源。各站独立读取真实分类和筛选定义，再使用其实际分类 ID、筛选 key/value 发请求。全部／影视等泛目录只有明确提供电影、电视剧、综艺选项时参与；不能提供所选条件的站源会提示不支持，不猜分类编号，也不退回普通片单冒充筛选结果。

18+ 默认关闭，仅本次主动筛选有效；离开入口、重新进入、重启和配置切换均关闭。旧版本保存的成人选择也不恢复。普通模式排除明确成人分类及成人元数据；18+ 模式要求明确成人分类或筛选值。首页、热播、榜单继续使用原有提供方，解析时排除明确成人元数据，不使用成人聚合结果。判定依据分类、标签、内容评级，不读取剧情或演员，不以站源名称判断。站源未标注的内容不能由本功能保证通用年龄认证。

卡片保留实际站源，站源 key + 影片 ID 为聚合身份；多个站源的相同 ID 不互相覆盖，点按进入对应站源详情。非首页 type 4 站源的远程扩展在详情／播放请求中通过有超时的私有副本解析，原始站源身份保持稳定。配置切换立即取消旧请求、清列表、撤销成人选择；成功或回滚后按当前配置重新读取，旧回调不能恢复旧列表。JS/Python/Jar 缓存包含 API/ext 身份，避免同 key 替换配置时复用旧插件。

请求有并发上限和超时，每站每类独立分页，失败页可重试；重试保留成功页。被成人过滤清空的原始页仍能进入下一页，重复页会终止，追加不改变已有卡片位置。评分／年份排序对每次完成的聚合批次生效，后续页追加；不同站源缺少统一热度及精确首映时间数据时，使用真实源默认顺序或可用年份，不承诺跨站完整全库排序。

保留已调整的筛选透明度、焦点和入口布局。“已加载 XX 部”成功行继续隐藏；加载、空、失败、部分不支持和重试状态保留。搜索、卡片／集数／评分样式、天气及配置／线路界面保持用户已验收的设计。

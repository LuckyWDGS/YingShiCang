# 首页源图标与天气文案 · 1.0.2

版本：1.0.2 / versionCode 58。沿用已有正式签名，支持覆盖升级。

## 本次修改

- 首页天气移除“约”和英文近似符号“≈”。保留当前位置确认、缓存隔离、中文/英文城市显示、过期天气提示和无障碍描述中的定位来源。
- 首页独立图标只读取 TVBox 配置的 `logo` 字段，支持 GIF 动画和静态图片。没有地址、空白地址、加载失败或图片损坏时隐藏图标，并收起宽度和间距。
- 初始布局隐藏图标；明确指定图片解码尺寸，确保隐藏状态也能完成加载。成功后才显示，换源时取消旧图片请求。
- 保留原 App 启动图标及源名称，包括源名称自带的 emoji。

## 验证

- TV ARM64、ARMv7 正式包及 mobile ARM64 编译成功。
- 两个正式包的应用 ID、版本、非调试属性、v2 签名、相同发布证书和 16KB 对齐检查通过。
- 雷电模拟器使用最终签名 ARM64 包，43 项检查通过：覆盖升级、已有首页、配置加载、无图/404/损坏图片隐藏及间距收起、GIF 实际帧变化、切换后迟到图片不回显、同一地址临时失败后恢复、静态源图兼容，以及实际天气不含近似前缀。
- 全部 1218 个原有内部文件及外部目录清单按 SHA256 恢复验证；原 ADB 映射保留，临时测试工具和映射移除，最后回到首页。已安装 APK 与发布文件 SHA256 相同。
- 本次未重复历史 JVM 全量测试，也未在实体手机验证。受控图片服务用于覆盖成功、失败和延迟场景，不代表所有外部源始终可用。

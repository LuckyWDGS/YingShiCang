# 配置弹窗精简与线路自动命名 — 2026-09-27

版本0.1.16-alpha /17。用户认为前版配置窗口难看且复杂，并补充线路名称最好自动获取。

## 交付
- 电视端紧凑弹窗：添加线路标题、左侧标准二维码、右侧唯一配置链接输入框及添加按钮；关闭移到右上角。没有名称输入框、保存/保存并启用双选择、底部大留白或长篇说明。
- 网址与配对码收进手动连接，可展开/收起；扫码路径直接配对，原认证不变。
- 添加只保存，在线路中选择启用。手机网页同样只输入链接。
- 自动命名顺序：同链接已有名称优先；配置顶层name/title/config_name；无有效元数据或网络失败时使用可读文件名，否则域名。不会使用内部sites[]或仓库子条目的名称冒充整合源名。已有显式name API兼容保留。
- 后台识别，6秒请求超时、2MB读取上限，不执行源插件；支持复用现有配置解码方法。保存锁只保护数据库写入，网络不持有锁。

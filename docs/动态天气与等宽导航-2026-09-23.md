# 动态天气与等宽导航

版本0.1.12-alpha / versionCode13，ARM64 debug。

- 天气状态改为原生动态图标，右侧保留城市和温度。晴天光芒转动、夜间月亮/星光、多云云层移动、雨滴下落、雪花飘落，另支持雾、雨夹雪、雷雨。
- 图标根据真实Open-Meteo天气代码和昼夜字段切换；缓存保存天气代码、城市、温度、昼夜，旧文本缓存自动重新获取。条件文字仅供无障碍描述，不再显示在天气行。
- 动画离开页面/不可见时停止，尊重系统关闭动画设置；未知天气显示中性图标，不伪装晴雨。
- “历史”移至第二排最左侧，第一排为8个分类，第二排为7个功能。两排分别等宽铺满，不再使用按文字宽度变化的分类按钮，也取消功能入口的焦点缩放。
- 两排各自统一高度、间隔与左右边距。分类页继承原来隐藏功能行的行为；历史页按返回回到主页。
